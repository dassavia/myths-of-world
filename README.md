# Мифы Миров (Myths of Worlds)

Мод для **Minecraft 1.21.1 на NeoForge** о шести мифологиях. Готовы греческая часть (Эллада) и скандинавская (Йотунхейм); для славянской, океанийской, египетской и индийской созданы заготовки миров.

## Скачать и установить

**[⬇ Скачать последнюю версию](https://github.com/dassavia/myths-of-world/releases/latest)** (файл `mythsofworlds-*.jar` в разделе Assets)

1. Установите [NeoForge](https://neoforged.net/) для Minecraft 1.21.1 (21.1.172 или новее): запустите установщик и выберите «Install client».
2. Положите скачанный `.jar` в папку## Что уже есть (v0.2.0)

### Греческая мифология: Эллада

- **Мрамор**: 2 диорита + 2 кальцита → 4 мрамора (в Элладе встречается в горах). Из мрамора: мраморные кирпичи (4 → 4) и мраморная колонна (2 → 2).
- **Олимпийский мрамор** (рамка портала): 8 мрамора вокруг золотого слитка → 8 блоков.
- **Факел Прометея** (зажигалка, 16 использований, без формы): кремень + золотой слиток + олимпийский мрамор + факел.
- **Врата Эллады**: замкнутая вертикальная рамка из олимпийского мрамора (как портал в Незер), ПКМ факелом внутри, постоять ~3 секунды.
- **Измерение Эллада**: смена дня и ночи, 7 биомов: *Вершины Олимпа*, *Елисейские поля*, *Рощи Аркадии*, *Асфоделевые луга* (с цветком асфоделем), *Стигийские топи*, *Эгейское побережье* и *Эгейское море*.
- **Структуры**: Храм Олимпийцев (Парфенон со статуей Зевса), Дельфийский оракул, Лабиринт Минотавра, Врата Аида, Логово Лернейской гидры, Логово Медузы, Пещера циклопа (с овцами Полифема), Логово Немейского льва. В каждой есть сундук с добычей.
- **Мобы**: сатир (Аркадия), гарпия (летает над горами и побережьем), спарт (скелет-воин из зубов дракона, не горит на солнце), тень умершего (полупрозрачная, накладывает слабость и тьму), пегас (приручается как лошадь, высоко прыгает, планирует, не получает урона от падения).
- **Полубоссы** (жёлтая шкала здоровья):
  - *Циклоп* — огромный, топает и подбрасывает всех вокруг. Роняет глаз циклопа.
  - *Медуза Горгона* — её взгляд замедляет, а через 3 секунды начинает обращать в камень. Щит в руке защищает, как зеркальный щит Персея. Роняет голову Медузы: ПКМ ею обращает в камень всех существ перед вами.
  - *Немейский лев* — стрелы и любые снаряды отскакивают от шкуры, бить только в ближнем бою. Роняет шкуру.
- **Боссы**:
  - *Минотавр* (300 HP) — в центре лабиринта, разгоняется и таранит рогами. Роняет рог Минотавра.
  - *Лернейская гидра* (400 HP) — пять голов плюются ядом, раны затягиваются сами. Огонь (зачарование «Заговор огня», горящие стрелы, лава) останавливает регенерацию на 10 секунд и ранит вдвое сильнее, как у Геракла.
  - *Цербер* (350 HP) — трёхглавый пёс у Врат Аида, не горит, поджигает укусом и дышит тремя огненными шарами.
- **Амброзия** — пища богов из храмов: регенерация и поглощение урона.
- Яйца призыва всех мобов во вкладке творческого режима.

Текстуры пока временные (нарисованы скриптом `tools/gen_greek_assets.py`); любую картинку можно заменить своей.

### Скандинавская мифология: Йотунхейм

- **Рунный камень** — блок рамки портала. Рецепт: 8 каменных кирпичей вокруг лазурита дают 8 рунных камней.
- **Рунное огниво** — открывает портал (16 использований). Рецепт (без формы): кремень + железный слиток + рунный камень + осколок аметиста.
- **Портал Бифрёст** — замкнутая вертикальная рамка из рунного камня, ПКМ огнивом внутри.
- **Йотунхейм** — вечные сумерки, горный рельеф, биомы *Ледяные пустоши* и *Тайга великанов*.

### Заготовки остальных мифологий

У каждой есть свой класс в `mythology/<имя>/` и измерение на ванильных биомах, но пока нет портала и своего содержимого.
Попасть туда можно командой `/execute in mythsofworlds:<id> run tp @s ~ 120 ~`.

| Мифология | Мир | id |
|---|---|---|
| Славянская | Навь (тёмные леса, вечные сумерки) | `nav` |
| Океанийская (полинезийская) | Гаваики (тёплое море и острова) | `hawaiki` |
| Египетская | Дуат (пустыня, вечная ночь) | `duat` |
| Индийская | Сварга (джунгли, вечный полдень) | `svarga` |

 (ледяные шипы) и *Тайга великанов*. При первом переходе там строится обратный портал.

## Сборка

```bash
./gradlew build              # jar в build/libs/
./gradlew runClient          # запустить игру с модом
./gradlew runGameTestServer  # автотесты порталов, данных, структур и мобов
./gradlew runSmokeTest       # сервер генерирует все миры, биомы и структуры (нужен run/smoke/eula.txt с eula=true)
```

Нужна Java 21. GitHub Actions собирает jar и прогоняет тесты на каждый push. После push в `main` jar автоматически публикуется на странице
[Releases](https://github.com/dassavia/myths-of-world/releases). Новый релиз создаётся, когда меняется `mod_version`
в `gradle.properties`; иначе обновляется файл в текущем релизе.
