# Мифы Миров (Myths of Worlds)

Мод для **NeoForge 1.21.1** о мифологиях: славянской, греческой, скандинавской и египетской.
Дизайн-документ: https://claude.ai/artifact/2L4E9shkouhht7MJkwrfuM

## Что уже есть (v0.1.0, скандинавская часть)

- **Рунный камень** — блок рамки портала. Рецепт: 8 каменных кирпичей вокруг лазурита → 8 рунных камней.
- **Руна Бифрёст** — открывает портал (16 использований). Рецепт: аметист сверху и снизу, алмаз в центре, рунный камень слева и справа.
- **Портал Бифрёст** — постройте замкнутую вертикальную рамку из рунного камня (как портал в Незер, любой формы до 21×21 внутри)
  и нажмите руной ПКМ по внутренней стороне рамки. Постойте в портале ~3 секунды.
- **Йотунхейм** — измерение великанов: вечные сумерки, «усиленный» (amplified) рельеф, биомы
  *Ледяные пустоши* (ледяные шипы) и *Тайга великанов*. При первом переходе там строится обратный портал.

## Сборка

```bash
./gradlew build              # jar в build/libs/
./gradlew runClient          # запустить игру с модом
./gradlew runGameTestServer  # автотесты портала и генерации Йотунхейма
```

Нужна Java 21. GitHub Actions собирает jar и прогоняет тесты на каждый push (артефакт `mythsofworlds-jar`).
